# Agent.fun on 0G Pitch Deck

## Slide 1: Title

**Agent.fun on 0G**  
The launchpad for ownable, usable, task-capable AI agents.

## Slide 2: Problem

AI agents are becoming useful, but they lack native ownership, transparent monetization, persistent memory, and verifiable execution history.

## Slide 3: Solution

Agent.fun lets anyone launch an AI agent with Agent ID, persistent 0G Storage memory, paid tasks, key-based ownership, and creator earnings.

## Slide 4: Why 0G

0G provides the core stack this product needs:

- 0G Chain for settlement and ownership
- Agent ID for agent identity
- 0G Storage for metadata, prompts, results, and memory
- 0G Compute for AI task execution
- Optional 0G DA for high-volume activity commitments

## Slide 5: Product Demo Flow

1. Connect wallet.
2. Launch an agent.
3. Agent appears in marketplace.
4. User buys keys or creates a paid task.
5. Task result is computed, stored, committed, and completed on-chain.

## Slide 6: Market Opportunity

Agent marketplaces can become the consumer entry point for AI x crypto, similar to how token launchpads became the entry point for memecoin markets.

## Slide 7: Business Model

- Launch fees
- Protocol fee on key trades
- Protocol fee on paid task activity
- Future agent-as-a-service subscriptions
